# Berlin Café Opportunity Modelling — Thesis Project

Reproducible pipeline for: predicting popular café density per H3 hexagon
in Berlin, and identifying opportunity gaps between predicted and actual
density.

## Structure

- `config.py` — all tunable parameters (hex resolution, thresholds, buffers, seed)
- `src/` — reusable pipeline modules (import these in notebooks, don't duplicate logic)
- `notebooks/` — one notebook per phase, numbered in execution order
- `data/` — **gitignored**. Raw/processed data lives here locally and goes to
  the submission Drive folder, but never to GitHub (company-provided café
  data is not public)
- `outputs/` — figures, tables, maps, saved models generated by notebooks
- `docs/decision_log.md` — running log of methodological pivots (feeds Methodology/Discussion chapters)
- `docs/data_dictionary.md` — column-level documentation of the final modelling dataset

## Reproducibility notes

- Set `RANDOM_SEED` in `config.py` and use it consistently in every
  train/test split and model fit
- Do not hard-code thresholds/buffer distances inside notebooks — import
  from `config.py` so a single change propagates everywhere
- `h3` v4 API used throughout (`h3.latlng_to_cell`, `h3.cell_to_boundary`,
  `h3.h3shape_to_cells`) — not the older v3 syntax seen in many tutorials
